# SWYNEX Final Data Analytics Project

## Retail Sales Data Analytics & Business Intelligence

### Problem Statement

Retail businesses generate large amounts of sales transaction data, but raw sales data can be difficult to interpret for effective business decision-making. This project focuses on analyzing retail sales data to understand sales performance across different product categories and regions. The analysis aims to identify revenue and quantity patterns, understand product and regional performance, and generate meaningful business insights using data analytics and visualization techniques.

## Dataset Information

This project uses a Retail Sales Dataset containing transactional sales information. The dataset includes details such as Order ID, Date, Customer ID, Product Category, Order Quantity, Unit Price, Region, and Revenue.

### Dataset Summary

- Number of Records: 8,010
- Number of Customers: 499
- Product Categories: 5
- Regions: 4
- Total Quantity Sold: 40,033
- Total Revenue: ₹3,20,67,213

## Project Objectives

- Analyze overall retail sales performance.
- Understand revenue and quantity patterns.
- Compare sales performance across product categories.
- Analyze regional sales performance.
- Identify meaningful business insights.
- Build an interactive dashboard using Power BI.

## Data Cleaning Process

The dataset was reviewed and prepared before analysis. The cleaning process included:

- Checking the dataset structure and columns.
- Identifying missing or inconsistent values.
- Checking for duplicate records.
- Verifying data types.
- Reviewing numerical fields such as quantity, unit price, and revenue.
- Preparing the cleaned dataset for analysis and visualization.

## Data Analysis

Microsoft Excel was used for data analysis and exploratory analysis.

The analysis focuses on:

- Sales and revenue analysis.
- Product category performance.
- Regional performance.
- Quantity sold analysis.
- Customer-related sales patterns.

## Power BI Dashboard

An interactive Power BI dashboard was developed to visualize the retail sales data.

The dashboard provides insights into:

- Total Revenue
- Total Quantity Sold
- Sales Performance
- Product Category Performance
- Regional Performance
- Revenue and Quantity Trends

## Key Business Insights

The analysis and dashboard help identify:

- Revenue contribution across different product categories.
- Differences in sales performance between regions.
- Quantity and revenue patterns.
- Product categories and regions requiring further business attention.
- Overall retail sales performance.
